# Human Review — Identidad

Human Review es un proyecto de Punto por Punto para permitir revisión visual y edición de HTML dentro de ChatGPT mediante MCP + UI + Skill, preservando explícitamente los cambios humanos cuando el modelo aplica feedback posterior.

## Project ID

`human-review`

## Repository

`PuntoxPunto/Human-review-pluggin`

## Rol dentro de Punto por Punto

Proyecto desarrollado públicamente durante el Lab y primer caso real para validar Project Packs y federación de contexto/Graph entre repositorios.

## Principio de gobernanza

La memoria mínima del proyecto vive en `.punto/` dentro de su propio repositorio. Punto por Punto puede indexarla y conectarla, pero no duplica esa memoria como una segunda fuente de verdad.
